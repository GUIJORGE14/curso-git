# curso-git
Neste curso, os alunos aprenderam os conceitos fundamentais e as principais práticas de versionamento de código utilizando Git e GitHub, ferramentas essenciais para desenvolvimento colaborativo. Foram abordados desde os comandos básicos até o fluxo completo de trabalho com repositórios locais e remotos.

 Conteúdo ensinado:

1. Git e versionamento

Entendimento do que é controle de versão e por que ele é importante.

Criação de repositórios locais com git init.

Estrutura do Git (working directory, staging area e repositório).

2. Ciclo básico de alterações

git add: adiciona arquivos/modificações ao staging area.

git commit: registra um snapshot do projeto com uma mensagem descritiva.

git status: verifica o estado atual do repositório (arquivos modificados, adicionados ou não rastreados).

git log: visualiza o histórico de commits.

3. Trabalho com repositórios remotos

Conexão com o GitHub através de git remote add origin.

Envio de código para o repositório remoto com git push.

Atualização do repositório local com git pull para integrar mudanças feitas por outras pessoas.

4. Gerenciamento de branches

Criação e troca de branches com git branch e git checkout.

Fluxo de trabalho com branchs para desenvolvimento paralelo.

Resolução de conflitos de merge e boas práticas de integração.

5. Fluxos de colaboração

Uso do GitHub para armazenar e compartilhar projetos.

Criação de repositórios remotos e organização de versões.

Conceitos de colaboração, forks, pull requests e revisão de código.

Ao final do curso, os alunos estão aptos a controlar versões de projetos, colaborar em equipes, manter histórico de alterações organizado e utilizar o GitHub como plataforma central de hospedagem de código.
